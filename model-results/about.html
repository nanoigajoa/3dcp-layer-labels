어떤 순서로 진행했나요?

최신 프로젝트 README를 기준으로 정리했습니다.

01

원본 사진 확인

Data 1~6의 252장을 읽고 이미지가 열리는지, 해상도와 중복, 밝기와 표면 차이를 확인했다. 받은 원본은 그대로 보존했다. 현재 사진은 1025×1025이며 촬영·가공 이력과 실험 출처는 아직 충분히 확인되지 않았다.

02

층 사이 경계 자동 표시

층 사이의 어두운 홈과 주변 밝기 차이를 이용해 경계 후보를 찾고, 끊긴 후보를 연결했다. 원본 위에 빨간 선을 얹은 그림은 사람이 확인하기 위한 화면이며, 학습 표적은 별도의 흑백 mask다. Data 2는 콘크리트 전체를, Data 4는 앞쪽 하부 벽을 대상으로 원본 특징에서 경계를 다시 찾았다. 기존 학습 라벨은 feature-refined-v4로 보존했다. 공개 최신 라벨 front-wall-v2는 사진마다 선택한 앞면의 기존 경계 곡선을 따라 뒤벽·기계·윗면 오검출을 삭제했다. 화면과 다운로드 mask를 함께 갱신했으며 이 수정본으로 학습을 시작하지 않았다.

03

애매한 라벨 구분

Data 2의 41·52·54번과 Data 4의 24·25번은 경계를 확실히 판단하기 어려워 이번 학습·평가에서 제외했다. 갤러리에는 이유와 함께 남겼다. 점수가 낮아서 제외한 사진은 아니다. 나머지 라벨도 자동 후보이며 사람이 모두 정답으로 확정한 것은 아니다.

04

학습·검증·보류 분리

같거나 비슷한 장면이 학습과 검증에 섞이지 않도록 잠정 그룹을 유지했다. Data 1+3과 Data 5+6의 121장은 학습, Data 2의 89장은 검증, Data 4의 37장은 보류로 나눴다. Data 4는 라벨 개발 때 이미 확인했으므로 엄격히 보지 않은 독립 test라고 부르지 않는다.

05

AI 학습과 최적 모델 선택

빨간 선이 없는 원본 RGB 사진을 AI에 입력하고, 자동 경계 mask를 맞추도록 학습했다. 실행을 확인한 뒤 최대 100 epoch와 조기 종료 조건으로 본 학습을 진행했다. Mac GPU 발열을 줄이기 위해 중단·재개와 배치 사이 휴식을 적용했다. 검증 loss가 10 epoch 연속 개선되지 않아 56 epoch에서 끝났고, 가장 낮은 검증 loss를 얻은 46 epoch 모델을 선택했다.

06

같은 사진에서 결과 비교

학습 121장과 검증 89장의 예측을 모두 저장하고, 보류 37장과 제외 5장도 원본·자동 라벨로 표시한다. 공개 비교에서는 자동 라벨·현재 모델·최신 후처리를 같은 사진 슬롯에서 갱신한다. 고정 검증 89장 기준 F1은 현재 모델 72.05%, 최신 후처리 83.85%다. 누락과 악화 사진을 제외하지 않는다. 학습 사진의 예측은 이미 본 장면에서의 결과이므로 일반화 성능으로 해석하지 않는다.

다음 단계

실제 경계를 얼마나 잘 찾는지 확인합니다.

새 Mac 재학습은 준비 완료이며 사용자가 직접 실행한다. Python 3.10.12 / PyTorch 2.5.1 / MPS에서 논문 핵심 설정을 맞추고, Data 1+3·Data 2·Data 5+6을 순환 검증하는 잠정 3-fold를 사용한다. 기준과 밝기·대비 증강 조건을 같은 초기 seed로 비교한다. **실제 사진 학습은 아직 시작하지 않았다.** 방법론과 실행 명령을 참고한다.

252장을 모두 손으로 수정하기 전에 저장된 모델 확률의 검출 기준·짧은 연결·잡음 제거·중심선 정리를 비교했다. 기존 후처리 76.05%를 같은 경로에서 갱신해 최신 F1 83.85%, Precision 90.71%, Recall 79.78%를 얻었다. 설정 선택에 사용하지 않은 45장도 F1 80.95%다. 라벨·평가 89장·±2픽셀 기준은 유지했다. 이 점수는 자동 라벨 일치도이며 실제 정답 정확도를 별도로 확인해야 한다.

다음 사람 작업은 처음부터 선을 그리는 대신 첫 24장 검수 도구에서 유형별 사례와 판단 보류·오류 후보를 확인하는 것이다. 이 24장은 검수 시작 묶음이며 나머지 사진의 정확도를 보장하거나 전체 검수를 대체하지 않는다. 실제 정확도 평가용 일부 사진은 자동 표시를 보지 않고 독립적으로 경계를 판정해야 한다. 수작업 최소화 결과와 남은 단계에 실험과 남은 자동 작업을 정리했다.

자동화로 더 할 수 있는 다음 학습 실험은 밝기·대비 변화 등을 넣은 증강 학습과 잠정 그룹을 유지한 3-fold다. 새 촬영·시편 평가는 별도로 필요하다. 3-fold는 아직 구현·실행하지 않았으며, 그룹을 유지한 5-fold와 별도 test에는 추가 독립 실험이 필요하다.

현재 calibration, mm/pixel, sub-pixel 위치 정확도, 레이어 두께·변형률은 검증하지 않았다. 예측 좌표는 정수 픽셀 좌표이며 물리적 측정치로 해석하지 않는다.

현재 결과를 읽을 때

46 epoch 모델의 F1은 72.05%, 같은 모델의 최신 후처리는 83.85%입니다. 둘 다 Data 2의 자동 라벨과 비교한 개발 검증 점수입니다. 다른 그룹의 검증은 새 3-fold 재학습을 실행한 뒤 확인합니다. 사람이 확인한 경계 정확도, 새로운 시편에서의 강건성, 실제 두께나 변형률을 입증한 결과는 아닙니다.
