**공개 최신 라벨은 앞면 전용 `front-wall-v2`이다.** 전체 252장을 확인하고 29장에서 뒤벽·기계·윗면 오검출을 삭제했다. 지정한 Data 2의 14장 분기·누락 경계와 Data 4의 37장 왼쪽 하단 경계를 추가로 보완했다. Data 4의 24·25번은 앞면이 확인되지 않아 보류를 유지한다. 이번 추가 작업은 지정 사진 이외 199장의 파일을 보존했다. 같은 홈페이지 카드와 다운로드 파일을 갱신하며 기존 학습 라벨과 실험 기록은 보존한다.

실제 3D 프린팅 콘크리트 사진에서 층 사이 경계를 찾는 프로젝트다. 원본 사진에 자동으로 경계를 표시하고, 원본–경계 mask 쌍으로 AI를 학습한 뒤 다른 사진에서 결과를 확인한다.

**현재 본 학습은 완료됐다.** 56 epoch에서 조기 종료했으며, 검증 loss 기준 최적 모델은 **46 epoch**다. 종전 feature-refined-v4 자동 라벨 기준으로 현재 모델의 F1은 72.05%이며, 같은 검증 사진과 자동 라벨에서 최신 후처리 F1은 **83.85%**로 Data 2의 개발 기준 80% 이상을 넘었다. 다른 그룹의 성능은 재학습 교차검증으로 확인해야 한다. 사람이 확정한 실제 경계 정확도나 새로운 실험에서의 성능을 입증한 점수는 아니다.

## 진행 과정

### 1. 원본 사진 확인

Data 1~6의 252장을 읽고 이미지가 열리는지, 해상도와 중복, 밝기와 표면 차이를 확인했다. 받은 원본은 그대로 보존했다. 현재 사진은 1025×1025이며 촬영·가공 이력과 실험 출처는 아직 충분히 확인되지 않았다.

### 2. 층 사이 경계 자동 표시

층 사이의 어두운 홈과 주변 밝기 차이를 이용해 경계 후보를 찾고, 끊긴 후보를 연결했다. 원본 위에 빨간 선을 얹은 그림은 사람이 확인하기 위한 화면이며, 학습 표적은 별도의 흑백 mask다. Data 2는 콘크리트 전체를, Data 4는 앞쪽 하부 벽을 대상으로 원본 특징에서 경계를 다시 찾았다. 기존 학습 라벨은 feature-refined-v4로 보존했다. 공개 최신 라벨 front-wall-v2는 사진마다 선택한 앞면의 기존 경계 곡선을 따라 뒤벽·기계·윗면 오검출을 삭제했다. 화면과 다운로드 mask를 함께 갱신했으며 이 수정본으로 학습을 시작하지 않았다.

### 3. 애매한 라벨 구분

Data 2의 41·52·54번과 Data 4의 24·25번은 경계를 확실히 판단하기 어려워 이번 학습·평가에서 제외했다. 갤러리에는 이유와 함께 남겼다. 점수가 낮아서 제외한 사진은 아니다. 나머지 라벨도 자동 후보이며 사람이 모두 정답으로 확정한 것은 아니다.

### 4. 학습·검증·보류 분리

같거나 비슷한 장면이 학습과 검증에 섞이지 않도록 잠정 그룹을 유지했다. Data 1+3과 Data 5+6의 121장은 학습, Data 2의 89장은 검증, Data 4의 37장은 보류로 나눴다. Data 4는 라벨 개발 때 이미 확인했으므로 엄격히 보지 않은 독립 test라고 부르지 않는다.

### 5. AI 학습과 최적 모델 선택

빨간 선이 없는 원본 RGB 사진을 AI에 입력하고, 자동 경계 mask를 맞추도록 학습했다. 실행을 확인한 뒤 최대 100 epoch와 조기 종료 조건으로 본 학습을 진행했다. Mac GPU 발열을 줄이기 위해 중단·재개와 배치 사이 휴식을 적용했다. 검증 loss가 10 epoch 연속 개선되지 않아 56 epoch에서 끝났고, 가장 낮은 검증 loss를 얻은 46 epoch 모델을 선택했다.

### 6. 같은 사진에서 결과 비교

학습 121장과 검증 89장의 예측을 모두 저장하고, 보류 37장과 제외 5장도 원본·자동 라벨로 표시한다. 공개 비교에서는 자동 라벨·현재 모델·최신 후처리를 같은 사진 슬롯에서 갱신한다. 고정 검증 89장 기준 F1은 현재 모델 72.05%, 최신 후처리 83.85%다. 누락과 악화 사진을 제외하지 않는다. 학습 사진의 예측은 이미 본 장면에서의 결과이므로 일반화 성능으로 해석하지 않는다.
